Figure 2 · Evidence gates

What can proceed—and what must wait

Developmental work can move forward without pretending that later evidence already exists. The gates protect the distinction between construction, resource release, computational validation, human validation, and deployment.

Freeze the measurement objects

No confirmatory P3 execution before freeze + preregistration/authorization.
02 / P3 → P4

Freeze the human study

Resolve populations/strata, N and power, evaluator condition, ethics/IRB, and preregistered endpoints.

No human or Prolific results before authorized fielding.
03 / P4 → P5+

Require a real deployment

Activate deployment papers only around an actual institutional setting, workflow, governance plan, and prospective questions.

No speculative claims of benefit or adoption.

Figure 3 · Author-review method

Use history as a control, not a magnet

The purpose of the historical versions is to detect drift without overwhelming the current review. The new version does not automatically win; the old version does not automatically win either.

Candidate → suspicion → anchor → decision

1. Read the candidate normally

Do not alt-tab sentence by sentence. First experience the manuscript as a reader.

2. Mark only real friction

Flag prose that feels abrupt, generic, over-programmatic, under-explained, or unlike the established voice.

3. Open the relevant anchor

Compare only that location or conceptual movement against the selected historical control.

4. Classify the difference

Gain · neutral modernization · voice loss · substantive loss · conceptual change · necessary correction.

5. Preserve correctness + strength

Keep newer conceptual accuracy while restoring older movement, examples, scope, or language when they were genuinely better.

6. Never wholesale-revert

The target is a current manuscript with historical authorial strength, not a return to an earlier project state.
